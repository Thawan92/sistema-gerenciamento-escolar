# Sistema de Gerenciamento de Notas Escolares

Aplicação desenvolvida para automatizar o controle de turmas, permitindo o cadastro de alunos, o lançamento de notas por professores e a consulta rápida do desempenho e médias da sala.

## Funcionalidades
* Cadastro e gerenciamento de alunos e turmas
* Lançamento de notas pelo perfil do professor
* Cálculo automático de médias e consulta de resultados

## Tecnologias utilizadas
* Java
